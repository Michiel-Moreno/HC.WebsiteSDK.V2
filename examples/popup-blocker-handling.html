🚫 Popup Blocker Detection Demo

v3.0 Feature: User-friendly error handling for WindowSurvey

✨ What's New in v3.0: WindowSurvey now detects when popups are blocked and triggers the onError callback with a helpful error message. This allows you to guide users to enable popups gracefully.
📋 How to Test:
  1. Ensure popup blocker is enabled in your browser (it usually is by default)
  2. Click "Open Survey in New Window"
  3. See the user-friendly error notification appear
  4. Follow instructions to allow popups
  5. Click "Try Again" to open the survey
✅ Success! Survey window opened successfully. If popup blocker is disabled, you'll see this message instead of the error notification.
⚠️ Popup Blocked! The browser blocked the survey popup. Check the notification in the top-right corner for instructions.

Features Demonstrated

  • Automatic popup blocker detection
  • User-friendly error messages via onError callback
  • Helpful guidance for enabling popups
  • Retry functionality

Browser Instructions

Chrome/Edge: Look for the popup blocked icon in the address bar

Firefox: Click the shield icon and allow popups

Safari: Safari > Preferences > Websites > Pop-up Windows

🚫 Popup Blocked

The survey couldn't open because your browser blocked popups.

To view the survey:

  1. Look for the popup blocked icon in your address bar
  2. Click it and select "Always allow popups from this site"
  3. Click "Try Again" below
