Basic Modal Survey Example

Simple ModalSurvey demonstration using CDN

📝 Note: Replace baseUrl, tenantId, and touchPointId with your actual Hello Customer values to see a real survey.

Configuration

baseUrl: 'https://your-domain.hellocustomer.com'
tenantId: 'your-tenant-id'
touchPointId: 'your-touchpoint-id'
language: 'EN'

Features Demonstrated

  • Creating a UrlBuilder with survey configuration
  • Instantiating a ModalSurvey
  • Showing and hiding the modal programmatically
  • Using lifecycle callbacks (onShow, onHide)
