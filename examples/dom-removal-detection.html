v3.0 Feature: Automatic cleanup prevents memory leaks in SPAs

✨ What's New in v3.0: When a survey element is removed from the DOM (e.g., during SPA route changes), destroy() is called automatically. This prevents memory leaks without manual cleanup!

How It Works

  1. Create Modal: Instantiate a ModalSurvey
  2. Show Modal: Display the survey to users
  3. Remove from DOM: Simulate SPA navigation by removing the modal container
  4. Automatic Cleanup: The SDK detects removal and calls destroy() automatically

Use Cases

  • React/Vue/Angular SPA route changes
  • Dynamic component mounting/unmounting
  • Conditional rendering
  • Any scenario where elements are removed from DOM
