🎨 ButtonTriggerSurvey Showcase

v3.0 Feature: Floating feedback buttons with 4 style presets

✨ New in v3.0: ButtonTriggerSurvey creates floating feedback buttons that can trigger any survey type (Modal, Inline, Window) or custom JavaScript functions. Features include 4 style presets, 8 positions, 30+ languages, and automatic cleanup.

Style Presets

Click a button below to create a feedback button with different styling:

1️⃣ Pill Button

Rounded button with text + optional icon

2️⃣ Circle Button

Circular button with icon only

3️⃣ Side Tab

Vertical tab on left or right edge

4️⃣ Banner

Full-width banner at top or bottom

Controls

Features

  • ✅ 4 style presets: pill-button, circle-button, side-tab, banner
  • ✅ 8 positions: corners, sides, top/bottom center
  • ✅ 30+ languages with automatic translation
  • ✅ RTL support for Arabic
  • ✅ Triggers ModalSurvey, WindowSurvey, or custom actions
  • ✅ Independent quarantine management
  • ✅ Automatic DOM removal detection (v3.0)

Available Positions

Corners: top-left, top-right, bottom-left, bottom-right
Sides: left-center, right-center
Center: top-center, bottom-center
